# HTTP /question

1. HTTP-слой находится в отдельном пакете FrontendAPI и зависит от rag.Answer,
   а не добавляется в ModelAPI. Один Retriever переиспользуется между запросами.
2. POST /question принимает один JSON-объект с непустым question, максимум 1 MiB.
   Неизвестные поля, дополнительные объекты и некорректный Content-Type отклоняются.
3. Role/Team поступают исключительно от внедрённого Authenticator. Демо-адаптер
   сопоставляет Bearer-токен с серверной записью. Неизвестный токен даёт 401,
   запрещённый доступ/роль — 403. Клиент не может назначить себе manager или team.
4. После успешной проверки вызывается Retriever.Answer с ограниченным контекстом.
   Общий дедлайн — 2 минуты, отмена клиента распространяется на зависимости.
   Сервер отдельно ограничивает чтение тела и запись ответа.
5. JSON-ответ сохраняет поля error, question, answer. Ошибки зависимостей не
   раскрываются клиенту. Таймаут — 504, прочая внутренняя ошибка — 500.
   Превышение тела — 413, таймаут его чтения — 408.
6. Отсутствие найденного контекста — успешный ответ о нехватке информации;
   это не внутренняя ошибка и не повод вызывать LLM без источников.
