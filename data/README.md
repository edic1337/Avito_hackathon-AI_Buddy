# Тестовые данные RAG

`kb/demo_onboarding.md` — синтетическая инструкция для проверки прототипа, а не
регламент Авито. Готовый экспорт `../embeddings.json` подготовлен из
`../ds-skills.md` и содержит 50 чанков с векторами размерности 1024 для
`Qwen/Qwen3-Embedding-0.6B`.

Метаданные экспорта сохранены как `origin: synthetic`, `min_role: intern`,
`team: null`. Источник указан переносимым идентификатором `repo://ds-skills.md`;
логический ключ импорта не является абсолютным путём. Не трактуйте этот набор
как опубликованные материалы или подтверждённые правила Авито.

## Импорт готовых векторов

После поднятия PostgreSQL с pgvector и применения обеих миграций задайте
выданный владельцем БД `DATABASE_URL`. Из каталога `backend` выполните:

```powershell
$env:RAG_COLLECTION = 'demo-qwen-v1'
go run ./cmd/rag import -file ../embeddings.json -source-key playbook/ds-skills.md
```

Импорт использует готовые векторы и не требует сервиса эмбеддингов. Не заполняйте
`rag.chunks` вручную. Файл `kb/demo_onboarding.md` — отдельный пример формата
Markdown с YAML-метаданными; для его загрузки через `ingest` понадобится сервис
эмбеддингов.
