# Проверки обновления

На копии присланного проекта успешно выполнены:

- npm ci, npm run build, npm run lint.
- node scripts/check-markdown.mjs: форматирование, сохранение номеров источников, экранирование HTML и отсутствие исполняемых ссылок.
- Go 1.27: go test ./... — FrontendAPI, ModelAPI, rag прошли; cmd/server и cmd/rag не содержат отдельных тестов.
- go vet ./... и go build ./cmd/server ./cmd/rag; для архива без Git использовался GOFLAGS=-buildvcs=false.
- Проверен YAML Compose и совпадение конфигурации API/CLI.
- Compose 2.40.3 подставляет один токен в прокси и в учётную запись стажёра в Go.
- Запрос без токена из браузера проходит через Nginx и доходит до обработчика с ролью стажёра. Прямой запрос к API без токена получает 401. Проверен также прокси Vite.
- `setup.ps1` проверен в PowerShell 7.5 с чистой конфигурацией и с существующим `.env.team`. Повторный запуск сохраняет токен, а настройки OpenRouter сохраняются при обновлении.

Добавлены тесты соответствия источников контексту LLM и проверки авторизации до выдачи источников.

## Ограничения проверки

Проверка Nginx и Go использовала тестовый ответ. После пересборки контейнеров отправь вопрос через сайт, чтобы проверить доступ к реальной модели.
Интеграционные тесты PostgreSQL пропускаются без TEST_DATABASE_URL.
